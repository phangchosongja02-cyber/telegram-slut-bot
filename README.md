# Telegram Slut Bot (OpenRouter Uncensored)

Fully whore AI chatbot for Telegram using a free uncensored model on OpenRouter.

## Setup (Termux or any Python environment)

1. Clone the repo
```bash
git clone https://github.com/phangchosongja02-cyber/telegram-slut-bot.git
cd telegram-slut-bot
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Create `.env`
```bash
cp .env.example .env
```

Fill in:
- TELEGRAM_BOT_TOKEN (from @BotFather)
- OPENROUTER_API_KEY (from https://openrouter.ai/keys)

4. Run it
```bash
python slut_bot.py
```
